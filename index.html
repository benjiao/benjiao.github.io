Intro to My Homelab

Last year, I got into homelabbing – the art of Cosplaying as a SysAdmin as Jeff Geerling calls it. Homelabbing is a term for setting up server infrastructure at home that lets one deploy and manage all sorts of different software stacks locally. Software like Immich, a centralized storage platform for my photos. …or Home Assistant, a home automation software stack that I use to control things like lights and power sockets based on sensors I deployed around the house. ...
